# Plume Photo Planner

แอป Streamlit สำหรับทดลองคำนวณเรขาคณิตเพื่อวางแผนสังเกตการณ์กลุ่มควันหรือแสงจากการปล่อยจรวด

## เริ่มใช้งานในเครื่อง

```bash
pip install -r requirements.txt
streamlit run app.py
```

## เผยแพร่ด้วย Streamlit Community Cloud

1. เปิด https://share.streamlit.io/
2. เข้าสู่ระบบด้วย GitHub และเลือก repository `meta43260-cyber/plume-photo-planned-`
3. เลือกไฟล์หลัก `app.py`
4. กด Deploy

## ข้อจำกัดสำคัญ

นี่คือแบบจำลองเพื่อการเรียนรู้และวางแผนเบื้องต้น ไม่ใช่การพยากรณ์วิถีจรวดจริง ความสูงและทิศทางเป็นค่าที่ผู้ใช้สมมติ แบบจำลองไม่รวมสภาพอากาศ ลม การหักเหของแสง ภูมิประเทศ หรือข้อมูลภารกิจจริง ห้ามใช้ผลลัพธ์แทน NOTAM ข้อมูลการบิน หรือคำแนะนำด้านความปลอดภัย
